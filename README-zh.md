# Startup Optimizer / 启动优化器

语言：[English](README.md) · 简体中文

社区插件一多，Obsidian 启动时就容易卡，手机端尤其明显。

启动优化器的思路很简单：用一张已安装插件清单，决定哪些插件启动时加载，哪些可以稍后加载，哪些暂时不需要启用。

它不是要做一个复杂的系统诊断面板。当前目标是把社区插件启动管理这件事做得更简单、更低负担。

## 为什么做启动优化器

Obsidian 插件很好用，但所有插件一起抢启动资源时，库就会变重。

启动优化器把选择压到更少：

- 重要插件启动时加载
- 不急用的插件稍后加载
- 暂时不用的插件直接停用
- 被启动优化器稍后加载过的插件，会显示简单的自测耗时

## 你可以用它做什么

- 用接近 Obsidian 原生体验的清单管理已安装社区插件
- 启动时机只保留两个选择：`启动时加载` 和 `稍后加载`
- 在同一个页面里启用或停用社区插件
- 启用插件排在上方，停用插件排在下方，每组内按插件名称排序
- 不导入 Obsidian 启动报表也能直接使用

## 安装方式

1. 从 Release Assets 下载 `main.js`、`manifest.json`、`styles.css`。
2. 在你的库中创建文件夹：`<vault>/.obsidian/plugins/startup-optimizer/`。
3. 把下载的三个文件放进这个文件夹。
4. 重启 Obsidian，并在第三方插件里启用 `Startup Optimizer`。

如果你直接从这个仓库安装，请使用仓库根目录里的构建产物，不要使用 GitHub 自动生成的 Source code 压缩包。

## 当前边界

Startup Optimizer 0.2.0 专注于低负担的社区插件启动控制。

它不会优化 Obsidian 核心插件、库加载、初始化流程或工作区布局，也不会自动读取 Obsidian 内部启动计时树。

版本说明：[0.2.0](release-notes/0.2.0-zh.md)
