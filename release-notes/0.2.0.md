# Startup Optimizer 0.2.0

Released: 2026-05-13

Startup Optimizer 0.2.0 makes the plugin much simpler to use. The settings page now focuses on the main job: manage community plugins, choose whether each plugin loads at startup or later, and reduce startup pressure without extra setup.

## What's New

- Reworked the settings page into a simple installed-plugin list.
- Replaced the old multi-stage startup controls with two choices: load at startup or load later.
- Added direct enable and disable control for community plugins from the same list.
- Enabled plugins now stay above disabled plugins, and each group is sorted by plugin name.
- Delayed plugins can show self-measured loading time after Startup Optimizer has loaded them.

## Removed From the Main Flow

- Removed the official startup report import flow from the current product surface.
- Removed drag sorting and detailed startup stage controls.
- Removed extra diagnostic sections that made the settings page harder to scan.

## Notes

- Startup Optimizer still does not optimize Obsidian core plugins, vault loading, initialization, or workspace layout.
- It does not automatically read Obsidian's internal startup timing tree.
- Source code is not public in this beta release.
