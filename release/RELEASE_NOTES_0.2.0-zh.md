# Startup Optimizer 启动优化器 0.2.0

语言：[English](0.2.0.md) · 简体中文

发布时间：2026-05-13

Startup Optimizer 0.2.0 有意把插件做得更简单，也更贴近手机端的真实痛点。

插件一多，Obsidian 手机端打开就容易慢；很多插件又不是按移动端启动速度来优化的。这一版不再要求用户先理解阶段、报表和排序规则，而是聚焦一个实际问题：这个社区插件应该启动时加载、稍后加载，还是暂时停用？

## 这版主要改变了什么

- 设置页改成简单的已安装插件清单。
- 启动时机只保留两个选择：启动时加载、稍后加载。
- 可以在同一张清单里启用或停用社区插件。
- 启用插件排在停用插件上方，每组内按插件名称排序。
- 被启动优化器稍后加载过的插件，可以显示简单的自测耗时。

## 主流程里移除了什么

- 官方启动报表导入不再作为当前产品主入口。
- 移除了拖拽排序和详细启动阶段控制。
- 移除了额外诊断区，让设置页更容易扫读。

## 当前边界

Startup Optimizer 仍然只专注于社区插件启动控制。

它不会优化 Obsidian 核心插件、库加载、初始化流程或工作区布局，也不会自动读取 Obsidian 内部启动计时树。

当前测试版不公开源码。
