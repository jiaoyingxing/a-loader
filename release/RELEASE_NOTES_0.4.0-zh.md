# A Plugins 0.4.0

这一版主要为开源和官方商店上架路线做准备。

## 变化

- 插件公开展示名改为 **A Plugins**。
- 插件公开简介改为：`Make plugin-heavy Obsidian vaults start smoother, especially on mobile.`
- 项目许可证改为 MIT。
- 仓库方向改为源码和构筑物一起公开在 GitHub。

## 保持不变

- 插件 ID 仍为 `startup-optimizer`，避免已有用户数据重置。
- 插件仍专注于社区插件启动时机与启停管理。
- 插件内部中文界面仍按需要保留“启动优化器”口径。
